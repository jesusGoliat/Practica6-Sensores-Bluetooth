# README for IAS — Práctica 6

Notas para asistentes de IA y para quien retome el proyecto. Contexto: dos apps
Flutter (Archivos IPN y Pares IPN) ampliadas con sensores, biometría, Bluetooth
Low Energy y consulta web por Bluetooth. Sin Firebase, Wi-Fi directo ni Internet
entre dispositivos.
